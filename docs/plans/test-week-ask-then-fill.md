# Testing week: ask how the set felt, then fill the next weight

His report, 15 Nov 2026, with a screenshot of a testing-week squat: *"I dont like the wording here "type it" and why
aren't we giving the user clear instructions on what to do?"* Sets 2 and 3 said "type it"; the only guidance was a
block of gym words (probe, reps in reserve, 5-10%) above the warm-ups, and after set 1 a row of "+1.25 · 26.25"
buttons that asked him to do the maths.

**His ruling, 15 Nov 2026, from three options: "Ask, then fill"** (over clearer words only, and over copying set 1's
weight down).

## What changes
- The card's line: "Find your weight this week: do set 1 at the weight shown, then tell us how it felt and we'll
  set the next one."
- The set-1 chip says "Set 1 · start at ~25kg" (was "probe at").
- Sets 2 and 3, before the set above is logged, show "after set 1" / "after set 2" in the weight box, never "type it".
  Anywhere else a box has no weight to offer, it says "enter".
- Once a set is logged, the next set's row asks "How was set 1 at 25 kg?" with Easy / About right / Hard. A tap puts
  the weight in the next set's box (still editable, still one tick to log), and the chosen answer stays lit.

## The weights (CSCS, mine, basis)
The testing week aims each set at 3-4 reps in reserve (RPE 6-7); the printed start is deliberately light (0.45-0.55
of the estimate), so the job is to climb.
- **Easy** (5+ reps left, RPE 5 or under): about 10% up, at least one plate step (not the old ladder's top rung, which
  is two steps on a light bar: 25 to 30 kg), snapped to the
  implement's real step and never past a stated kit limit. At the limit it stays at the same weight and the line says
  to add reps instead (the existing at-limit cue). Each rep in reserve is roughly 2.5-3% of load, so being two or
  more reps short of the target justifies the larger rung; the old line already said 5-10%.
- **About right** (3-4 left): the same weight. That set is the week's answer.
- **Hard** (2 or fewer left): about 5% lighter, at least one plate step, never below one step. Going past the target
  in a testing week is the error to correct, and one step is the smallest honest correction.
- The answer is NOT stored as the set's effort: the testing week's result is still read from the weights logged, as
  now (no change to how next week's weight is set). The one-tap "how did the lift feel" is still never asked in a
  testing week.

## Review (the five questions)
1. Training effect: the same search, made easier to follow; the climb is no bigger than the old buttons offered.
2. Takes away: the "same / +5% / +10%" buttons (the 5% rung is not offered directly; he can still type any weight).
3. Fundamentals: unchanged; nothing about the plan or progression moves.
4. Floors: none redefined; stated kit limits still cap the climb.
5. Scope: inside it.
